## 二、我们处理哪些信息，为什么

| 信息 | 用途 | 存在哪里 |
|---|---|---|
| 你写下的目标、关卡、每次讲述、回答、约好的下一小步 | 让伙伴记得你做到哪、生成回应 | 默认存在设备本地；登录养一只账号并开启同步后，也保存在腾讯云养一只独立服务 |
| 伙伴整理出的「它记得的事」 | 让回应更具体 | 随养一只存档保存于本机；登录并同步后同步到腾讯云。你可以在「设置 → 它记得的事」查看、修改、清空 |
| 养一只账号用户名、加盐密码摘要和原生客户端登录会话摘要 | 验证账号、在你的设备间同步存档 | 腾讯云养一只独立服务；不保存明文密码或原生会话令牌 |
| 设备号（随机生成，不含硬件信息） | 使用官方模型时按设备计算每日额度 | 你的设备；随请求发送到我们的模型网关 |
| 模型调用记录（提示词编号、模型、耗时、是否成功、被拦截的原因） | 发现故障、改进质量 | 你的设备；配置了上报地址时发送给我们。**不含你写的内容** |
| 你主动标记「这句话不太对」时，那一句伙伴说的话 | 改进它说话的方式 | 同上，仅在你点选时发送 |
| 使用时长（每天在前台的分钟数） | 时长提醒、未成年人模式 | 你的设备 |

我们不收集你的姓名、手机号、通讯录、位置、照片。

## 三、发送给大模型服务方的信息

为了生成回应，你讲述的内容、它记得的事、最近几次讲述会发送给大模型服务方：

- 使用「官方」模型时：经我们的模型网关转发给 [服务方名称]（模型 [名称]，备案号 [ ]）。网关不保存对话内容 [需与实际部署一致]。
- 使用你自己填写的 API 密钥时：直接发送给你选择的服务方，适用该服务方的隐私政策；我们收不到这些内容。

你可以在「设置 → 它的脑子」断开模型。断开后伙伴使用预先写好的台词，不再发送任何内容。

## 四、提醒

提醒由你的手机在本地按时间发出，不经过我们的服务器。你可以在「设置 → 提醒」关闭，或设置不打扰的时段。

## 五、你的权利

- 查看与修改：日记页、「它记得的事」。
- 导出：「设置 → 复制存档」。
- 删除本机数据：「设置 → 隐私与数据 → 删除全部数据」会删除本机数据并取消已排好的提醒。删除云端账号与存档：在「设置 → 云端同步 → 删除云端账号和存档」输入密码确认；服务端删除账号、云端存档和该账号原生会话。已下载的本机副本需另在各设备删除；加密备份按轮转周期保留，最长 7 天后清除。
- 撤回同意：断开模型、关闭提醒即可。

## 六、未成年人

我们的服务主要面向成年人。未满 18 周岁的用户请在监护人同意下使用，并在「设置」中开启未成年人模式：关闭自由聊天、22 点到次日 6 点不可使用、每天使用满 40 分钟提醒休息。[是否需要实名或年龄核验，待确认]

## 七、心理危机

当你的输入中出现可能涉及自身安全的表达时，伙伴不会继续正常对话，而是显示心理援助热线（12356）和紧急电话。这一识别在你的设备上完成，只记录发生的时间和级别，不记录内容。[是否需要通知紧急联系人，待产品决定后补充]

## 八、信息安全与保存期限

设备与服务端之间通过 HTTPS 传输。密码采用随机盐 scrypt 摘要；原生客户端会话仅以 SHA-256 摘要保存。账号云存档保留至你删除云端账号，服务端加密备份按 7 天轮转，删除后的备份最多保留 7 天。服务端部署在独立的腾讯云目录与服务中，不与拾光共享账号或数据。[补充运营方安全事件处置与通知方式]
