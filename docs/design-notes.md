# 养一只 demo 设计记录

目标管理 + AI 陪伴的原型。题材从《燎原》（森林、野火）换成「为一个目标孵一只小伙伴」。《燎原》原型保留，见同目录的 v1 记录（`liaoyuan-v1-notes.md`）。

- 日期：2026-11-13 做了第一、二版，2026-11-15 上线第三版
- 换题材的原因：森林版的美术和题材偏老气。

## 核心设定

它不是宠物，是搭档：一个目标孵一只，只关心这件事，记得你做过的每一步。

四条红线（写进了每次调用模型的人设提示词）：
1. 它不受苦（不饿、不病、不死，你不来它只是睡了）
2. 它不黏人（不说想念、不扮演恋人或唯一的朋友）
3. 它说实话（做得少就说少，不吹捧也不责备）
4. 它不占时间（聊天不长个儿，每次回复落到一个具体动作）

## 第二版：交互简化（用户反馈第一版「太复杂太难懂」）

第一版的问题：首屏有十来个新名词和四格数值面板；孵化是一张长表单；记录要自己选做了多少、看倍率；主按钮埋在屏幕下方。

第二版的原则：
- **一屏只做一件事**。主界面只有它、它说的话、一个黄色主按钮。
- **数值不上界面**。只留一条「成长」进度条。好奇心、羁绊、等级、倍率都不显示。
- **规则由它用话说，每条只说一次**：怎么玩、睡觉不会饿、过关会蜕壳、它会捡东西。
- **界面用词只留四个**：成长、关（里程碑）、下一小步（约定）、宝贝（捡的东西）。
- **引导改成三步，一屏一问**：想做什么 → 分成几关和今天的第一小步（默认不用改）→ 起名、选说话方式。
- **记录只要打一句话**。不再自报做了多少；下一小步由它给建议，点一下就行。
- **一轮讲完屏幕自动收起**，回到最简单的样子；整段对话在日记里。
- **次要内容收进二级**：路线（含过关和放归）、它捡的宝贝、设置。第一次来连导航都不显示。
- **所有宽度都是一条手机宽的单栏**。

## 第三版：质感（用户要求把品质做到极致）

判断：品质感主要不来自更多功能，而来自「它是活的」，以及每个关键时刻都有分量。交互结构沿用第二版，没有新增概念。

- **它会动**：眼珠跟着光标走，你打字时它看着输入框；没人理它时自己东张西望。尾巴、翅膀、触须各自摆动。换表情不重绘。戳它会被压扁弹回并回一句嘴，连戳五下有彩蛋。
- **贴纸白边**：整只伙伴外面一圈白色模切边，深浅背景都看得清。
- **场景**：它住在一小片场景里，天色跟真实时间走（清晨、白天、傍晚、夜里有月亮和星星）。白天的天色是这只伙伴自己的颜色。
- **宝贝有形状**：24 种宝贝各有图标，摆在场景里它的窝边；收藏页是 24 格图鉴，没捡到的是问号。
- **它说话有声音**：对白一个字一个字打出来，边打边「嘟嘟」，音高由体型和颜色决定，每只不一样；三种性格音色也不同。等它回话时是三个跳动的点，它在看天。
- **喂食的演出**：你发出去的话变成一颗光点飞进它嘴里，它咽一下，成长条弹一下，飘出「+2」。升级时原地跳起、放星星。
- **敲蛋**：孵化要自己点三下，每下多一道裂缝，最后炸开。
- **蜕壳的演出**：发抖、闪白、碎壳四溅，新长出的部位弹出来。长成时全屏彩屑，给一张成长证书。
- **声音**：全部用 WebAudio 现场合成，没有音频文件；设置里可关。支持的手机上有轻微震动。
- **二级页面重做**：路线是一条小路，过了的关挂着它蜕下的壳和壳上的字；栖地里每只都站在自己的场景里，点开是证书。
- **细节**：弹层从下方弹起，说话时舞台卡片收矮让出空间并吸顶，页面底是点阵贴纸本。减少动效的系统设置下所有演出自动关闭。

代码拆成：pet.js（规则）、critter.js（形象、场景、图标）、sfx.js（声音）、fx.js（粒子）、strings.js（文案与提示词）、app.js（界面）。

## 规则（pet.js，纯函数；名词是引擎内部的，界面上不出现）

- **见闻**（界面叫「成长」）：唯一的成长来源。讲一次 +2，回答它的问题 +2，约好下一小步 +2。同一天第 2 次减半，第 3 次起固定 1 点。
- **等级**：每一关内 0–7 级，升级要 4、6、8…点。
- **好奇心**：它醒着时自己攒，攒够就出门捡一样宝贝，价格每次 ×1.6。这是离开期间的收获。
- **醒/睡**：约好下一小步能醒 3 天，没约只醒一天半。睡着只是暂停。
- **回归加成**（界面叫「好久不见奖励」）：离开 d 天后第一次讲述，成长 × (1 + 0.5·√(d−1))。模拟确认按天平均单调下降。
- **补丁**：隔 5 天以上又回来，身上多一块补丁，定位是奖章。
- **蜕变 = 过关**：长出一个新部位，由这一关的做事方式决定（答得多→大眼睛，讲得细→角，来得勤→翅膀，不紧不慢→触须，其余→尾巴、肚甲）。旧壳上的纪念文字由模型在后台写好存进日记。
- **默契**（引擎里叫羁绊）跨目标保留，只在栖地页显示。
- **长成**后搬进栖地；**放归**是体面的放弃。

## 模型用在哪

拆关（含第一小步）、每次讲述后的一句回应 + 一个问题 + 下一小步建议（一次调用）、回来时「上次做到哪了」、不想动时的三个更小版本、自由聊天（每次最多 6 轮）、旧壳文字。
连不上模型时全部换成按性格预先写好的台词；聊天入口隐藏。

## 已知的缺口

- 没有推送：它不能主动找你
- 长期记忆只是把最近几条日记原样发给模型，没有压缩
- 栖地里的老伙伴不能继续聊
- 没有玩家可做的经济决策
- 云端存档和模型调用只用替身测过，真实对话质量未验证
- 声音和动效只在无头浏览器里验证过不报错，听感和手感没有真人确认
- 贴纸白边用了 SVG 滤镜，低端手机上的流畅度没测
- 付费、账号、多只同时养都没做

## 待验证

不看说明能不能在一分钟内完成第一次讲述；跟它说话是否比填表更想回来；它的追问是否具体到让人愿意答；形象够不够可爱；声音是加分还是打扰。
